# 📡 Wi-Fi Monitor (iw)

Интерактивный TUI-монитор Wi-Fi-сетей для Linux на чистом Bash. Работает напрямую через `iw` — **без NetworkManager**, без wpa_supplicant-CLI и без графических зависимостей. Показывает сети в реальном времени, уровень сигнала, каналы, тип защиты, загруженность каналов 2.4 ГГц и умеет на лету переключать адаптеры и диапазоны.

Один файл. Никакой сборки. Скопировал → `chmod +x` → запустил.

## ✨ Возможности

- **Полностью независим от NetworkManager** — только `iw`, `awk`, `sort` и встроенные средства Bash.
- **Фоновый сканер** — активное сканирование идёт в отдельном процессе, интерфейс не подвисает и не «набегает» построчно: кадр подменяется атомарно через `mv`.
- **Автоматический fallback на кэш ядра** — если активный скан недоступен (нет root, адаптер занят), читается `iw scan dump`.
- **Автоопределение адаптеров** — интерфейс, шина (USB/PCI/…), драйвер, модель USB-свистка, MAC, режим (`managed`/`monitor`/`AP`), состояние (`up`/`down`).
- **Определение поддерживаемых диапазонов** — парсится `iw phy … info`, частоты раскладываются на 2.4 / 5 / 6 ГГц, отключённые (`disabled`) игнорируются.
- **Фильтр по диапазону** — сканирование только нужных частот (`scan freq …`), что заметно быстрее полного скана.
- **Горячее переключение адаптера** — выдернул свисток, воткнул другой, нажал `a` — список обновится сам.
- **Гистограмма загрузки каналов 1–13** — сразу видно, где каша из соседских роутеров.
- **Шкала сигнала** — 10 блоков, цвет по качеству (зелёный / жёлтый / красный) + значение в dBm.
- **Тип защиты** — Open, WEP, WPA, WPA2, WPA3, WPA2/WPA3 (transition), WPA2-EAP.
- **Смена регдомена из интерфейса** — клавиша `c`, два символа страны, без выхода из программы.
- **Автоподнятие интерфейса** — если адаптер `down`, а скрипт запущен с root, он поднимет его перед сканом.
- **Аккуратный выход** — альтернативный экран терминала, курсор и `stty` возвращаются в исходное состояние при любом выходе, включая `Ctrl+C` и обрыв SSH.
- **Поддержка кириллической раскладки** — `q`/`й`, `a`/`ф`, `b`/`и`, `c`/`с` работают одинаково.

## 📋 Требования

| Компонент | Обязательно | Комментарий |
|-----------|-------------|-------------|
| Linux + `cfg80211`/`nl80211` | да | любой современный дистрибутив |
| `bash` ≥ 4.4 | да | ассоциативные массивы, `read -t`, `${var^^}` |
| `iw` | да | `sudo apt install iw` |
| `awk`, `sort`, `head`, `tr` | да | есть в базовой системе (mawk/gawk — оба подходят) |
| `tput` (ncurses-bin) | желательно | без него используется fallback на ANSI |
| `stty` (coreutils) | да | определение размера окна и режимов ввода |
| `ip` (iproute2) | опционально | только для автоподнятия интерфейса при root |
| `sudo` | опционально | для активного сканирования и смены регдомена |
| UTF-8 локаль | да | иначе рамки и кириллица «плывут»; скрипт сам выставит `LC_ALL=C.UTF-8` |
| Терминал ≥ 46×10 | да | для меню адаптеров — ≥ 50×12 |

Установка зависимостей в Debian/Ubuntu:

```bash
sudo apt update
sudo apt install -y iw ncurses-bin coreutils iproute2
```

## ⚡ Быстрый старт

```bash
# Список адаптеров и их возможностей — без TUI, годится для скриптов
./wifi-monitor-iw.sh --list

# Обычный запуск: один адаптер — сразу скан, несколько — меню выбора
./wifi-monitor-iw.sh

# Конкретный адаптер, обновление раз в 5 секунд, только 5 ГГц
sudo ./wifi-monitor-iw.sh wlan1 5 --band=5
```

Пример вывода `--list`:

```

2   wlan1        USB   managed   down     2.4/5/6   00:c0:ca:xx:xx:xx  Realtek RTL8832AU [rtw89_8832au]
```

## 🧰 Аргументы и ключи

```
./wifi-monitor-iw.sh [интерфейс] [интервал_сек] [--list] [--band=all|2.4|5|6] [--debug]
```

| Аргумент / ключ | По умолчанию | Описание |
|-----------------|--------------|----------|
| `интерфейс` | авто | Имя Wi-Fi-интерфейса (`wlan0`, `wlp3s0`…). Любая позиция. Если не задан: при одном адаптере выбирается он, иначе открывается меню. |
| `интервал_сек` | `3` | Любое целое число = пауза между сканами в секундах. Значения `< 1` приводятся к `1`. |
| `--list` | — | Напечатать таблицу адаптеров (шина, режим, статус, диапазоны, MAC, устройство) и выйти. TUI не запускается, root не нужен. |
| `--band=all` | `all` | Полный скан по всем поддерживаемым частотам. |
| `--band=2.4` | — | Только частоты ниже 3000 МГц. |
| `--band=5` | — | Только 3000–5924 МГц. |
| `--band=6` | — | Только 5925 МГц и выше (Wi-Fi 6E/7). |
| `--debug` | — | Включает `set -x`, весь трейс уходит в `/tmp/wifi-monitor.debug`. |

Порядок аргументов свободный: числа трактуются как интервал, всё остальное без `--` — как имя интерфейса.

Если запрошенный диапазон адаптером не поддерживается, скрипт **не падает**: он переключится на `all` и покажет предупреждение в строке статуса.

> ⚠️ Скрипт нельзя запускать через `source` / `.` — он использует `exit`, `trap` и `exec sudo`, что убило бы текущую оболочку. Встроенная проверка это блокирует.

## ⌨️ Управление с клавиатуры

### Основной экран

| Клавиша | Альтернативы | Действие |
|---------|--------------|----------|
| `a` | `ф`, `Tab` | Меню выбора адаптера (список обновляется в фоне) |
| `b` | `и` | Циклическое переключение диапазона: все → 2.4 → 5 → 6 → все |
| `c` | `с` | Задать код страны (регдомен). Требует root |
| `q` | `й`, `Ctrl+C` | Выход с восстановлением терминала |

### Меню выбора адаптера

| Клавиша | Альтернативы | Действие |
|---------|--------------|----------|
| `↑` / `↓` | `k`/`j`, `w`/`s` | Перемещение курсора |
| `1`…`9` | — | Мгновенный выбор адаптера по номеру |
| `Enter` | — | Подтвердить выбор |
| `Esc` | `q`, `й` | Назад (при старте — выход из программы) |

Список адаптеров опрашивается раз в секунду прямо в меню: можно воткнуть USB-свисток, не выходя из программы, и он появится сам.

### Ввод кода страны

По нажатию `c` в нижней строке появляется запрос на **2 символа** (`DE`, `PL`, `UA`, `US`…). Таймаут ввода — 30 секунд, `Enter` без ввода = отмена. Регдомен применяется через `iw reg set` и действует **до перезагрузки**.

## 🔧 Как это работает

```
┌──────────────────────────┐        ┌───────────────────────────┐
│  Основной цикл (UI)      │        │  Фоновый worker           │
│  ─────────────────────   │        │  ──────────────────────   │
│  раз в 0.5 с:            │        │  ip link set … up (root)  │
│   • проверка dump/parsed │        │  iw dev IFACE scan [freq] │
│   • awk-парсер + sort    │◀───────│  fallback: scan dump      │
│   • отрисовка кадра      │  файл  │  атомарная запись:        │
│   • чтение клавиши       │  dump  │  dump.new → mv → dump     │
│   • iw reg get / 5 с     │        │  sleep INTERVAL           │
└──────────────────────────┘        └───────────────────────────┘
```

1. **Worker** в бесконечном цикле делает полный блокирующий скан. Если вывод пуст (нет прав, `-EBUSY`, интерфейс занят) — берёт кэш ядра `iw scan dump`.
2. Результат пишется в `dump.new` и подменяется через `mv -f` — UI никогда не увидит半 записанный файл.
3. **Парсер на awk** разбирает блоки `BSS …`: частоту, сигнал, `last seen`, SSID, capability/RSN/WPA иauthentication suites. Записи со `last seen > 30000 мс` отбрасываются как устаревшие.
4. Номер канала вычисляется из частоты: `2484 → 14`, иначе `(f − 2407)/5` для 2.4, `(f − 5000)/5` для 5, `(f − 5950)/5` для 6 ГГц.
5. Сортировка — по уровню сигнала, сверху самые мощные. Подключённая сеть (`-- associated`) помечается зелёной стрелкой `▶`.
6. Качество в процентах считается как `2 × (dBm + 100)` с обрезкой в 0…100 (−50 dBm ≈ 100 %, −100 dBm ≈ 0 %).
7. Скрытые сети отображаются как `‹скрытая›`, escape-последовательности `\xNN` в SSID раскодируются.
8. Временные файлы живут в `mktemp -d` и удаляются при выходе; воркер убивается trap-ом по `EXIT`/`INT`/`TERM`/`HUP`.

## 🔐 Root, регдомен и каналы

### Зачем нужен root

| Возможность | Без root | С root |
|-------------|----------|--------|
| Чтение кэша сканирования (`scan dump`) | ✅ | ✅ |
| Активное сканирование (`scan`) | ❌ | ✅ |
| Смена регдомена (`iw reg set`) | ❌ | ✅ |
| Автоподнятие интерфейса (`ip link set up`) | ❌ | ✅ |

При запуске без root скрипт пробует `sudo -v` и, если получилось, перезапускает себя через `exec sudo`. Если sudo нет или пароль не введён — честно предупреждает и работает на кэше ядра. Данные при этом могут быть устаревшими: кэш наполняется тем, кто в системе реально сканирует (NetworkManager, wpa_supplicant и т. п.).

### Регдомен `00` — почему не видно половину 5 ГГц

`00` — это «world domain»: максимально консервативный набор правил. Часть каналов помечена `no IR` (нельзя инициировать излучение → только пассивный скан), часть вообще `disabled`. Симптом: сети 5 ГГц видны через раз или не видны вовсе.

Лечение — нажать `c` и ввести реальный код страны. Проверить вручную:

```bash
iw reg get                      # текущий регдомен
sudo iw reg set UA              # задать до перезагрузки
iw phy phy0 info | grep -A2 MHz # какие частоты разрешены и где no IR
```

Чтобы задать регдомен навсегда (Debian/Ubuntu):

```bash
# вариант через crda/wireless-regdb
sudo sed -i 's/^REGDOMAIN=.*/REGDOMAIN=UA/' /etc/default/crda

# или через systemd-сервис / NetworkManager, если он всё-таки установлен
```

Скрипт показывает регдомен в строке статуса и обновляет его каждые 5 секунд.

## 🖥️ Адаптивность интерфейса

Колонки включаются по ширине терминала — в узком окне остаётся самое важное:

| Ширина | Что добавляется |
|--------|-----------------|
| ≥ 46 | Маркер, SSID, канал, шкала сигнала + dBm (минимум для работы) |
| ≥ 56 | Гистограмма каналов 2.4 ГГц (если хватает строк по высоте) |
| ≥ 60 | Колонка «Защита» |
| ≥ 70 | Колонка «GHz» |
| ≥ 100 | Колонка «BSSID» |

В меню адаптеров: при ширине ≥ 80 появляются «Режим» и «Статус», при ≥ 110 — MAC.

По высоте: количество строк со списком сетей считается автоматически, лишние уходят в счётчик `(показано N)` в строке статуса. Если строк совсем мало — предупреждения скрываются первыми, список важнее.

При изменении размера окна экран перерисовывается начисто, без мусора от предыдущего кадра.

## 🌍 Переменные окружения

| Переменная | Назначение |
|------------|------------|
| `WIFIMON_SYSNET` | Путь к sysfs-каталогу сетевых интерфейсов. По умолчанию `/sys/class/net`. Полезно для тестов и нестандартных окружений. |
| `LC_ALL` / `LC_CTYPE` / `LANG` | Если ни одна не содержит UTF-8, скрипт принудительно выставит `LC_ALL=C.UTF-8`. |

Пример:

```bash
WIFIMON_SYSNET=/tmp/fake-sysnet ./wifi-monitor-iw.sh --list
```

## 🐞 Отладка

```bash
./wifi-monitor-iw.sh --debug
# в другом терминале:
tail -f /tmp/wifi-monitor.debug
```

В лог попадает полный `set -x` трейс плюс stderr всех вызовов `iw`. Полезно, когда список сетей пуст, а причины не obvious.

Быстрая ручная проверка того же, что делает скрипт:

```bash
iw dev                                    # интерфейсы и их phy
iw dev wlan0 scan | head -50              # активный скан (root)
iw dev wlan0 scan dump | head -50         # кэш ядра
iw dev wlan0 scan freq 2412 2417 2422     # скан по конкретным частотам
iw phy phy0 info | grep MHz               # разрешённые частоты
cat /sys/class/net/wlan0/operstate        # up / down / dormant
```

## 🛠️ Устранение неполадок

| Симптом | Причина / решение |
|---------|-------------------|
| `Нужен iw: sudo apt install iw` | Не установлен `iw`. |
| `Нужен интерактивный терминал` | Запуск не в TTY (пайп, cron, CI). TUI требует stdin+stdout на терминале. Для скриптов используйте `--list`. |
| `Окно мало: нужно от 46x10` | Увеличьте окно терминала или уменьшите шрифт. |
| `Сети не найдены (идёт сканирование?)` | Первый скан ещё не завершился — подождите пару секунд. Полный скан всех диапазонов может занимать 2–5 с. |
| `command failed: Device or resource busy (-16)` | Адаптер занят другим сканом или ассоциацией. Помогают: увеличить интервал, сузить `--band`, отключить фоновое сканирование NM для этого интерфейса. |
| `Сети не найдены` без root | Ожидаемо: активный скан запрещён, кэш пуст. Запустите через `sudo`. |
| `Адаптер … отключён — нажми [a]` | Свисток выдернули или интерфейс исчез. Нажмите `a` и выберите другой. |
| Не видно сетей 5 ГГц | Регдомен `00` → нажмите `c`, задайте страну. См. раздел выше. |
| Не видно сетей 6 ГГц | Нужен адаптер с Wi-Fi 6E/7, свежее ядро и корректный регдомен. Проверьте `--list`: есть ли `6` в колонке «ГГц». |
| Кракозябры вместо рамок | Шрифт терминала без псевдографики. Поставьте JetBrains Mono / Fira Code / DejaVu Sans Mono. |
| Всё «плывёт» по ширине | Не UTF-8 локаль. Проверьте `locale`, при необходимости `export LC_ALL=C.UTF-8`. |
| `rfkill` блокирует | `rfkill list` → `sudo rfkill unblock wifi`. |
| Интерфейс постоянно `down` | Драйвер/питание USB. Проверьте `dmesg -w`, отключите USB autosuspend для свистка. |
| Артефакты после выхода | `reset` или `stty sane; tput cnorm` — вернёт терминал в норму. |

## ⚠️ Ограничения

- Это **сканер/монитор**, а не сниффер: работает в обычном режиме через nl80211, не переводит адаптер в `monitor` и не занимается инъекцией. Для monitor-режима — `airmon-ng` / `iw` вручную.
- Гистограмма загруженности строится **только по каналам 1–13 (2.4 ГГц)** и показывает число найденных BSS на канале, а не реальную утилизацию эфира.
- Список ограничен высотой окна: сортировка по сигналу, слабые сети могут не влезть (счётчик «показано N» это индицирует).
- Активный скан кратковременно уводит радио с рабочего канала — при активном трафике возможны микрозадержки. Не ставьте интервал `1` на боевом линке.
- Требуется Bash ≥ 4.4: в `/bin/sh`, dash, zsh скрипт не запустится (shebang — `#!/usr/bin/env bash`).
- macOS/BSD не поддерживаются: там нет `iw` и `/sys/class/net`.
